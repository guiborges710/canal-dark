📌 OPÇÃO 1 — GitHub Pages (RECOMENDADO):

1. Va para: https://github.com/guiborges710/canal-dark

2. Clique em "Settings" (engrenagem, canto superior direito)

3. Na esquerda, clique em "Pages"

4. Em "Source", selecione:
   - Branch: new-video-style
   - Folder: / (root)

5. Clique "Save"

6. Aguarde 1-2 minutos

7. Uma URL aparecerá tipo:
   https://guiborges710.github.io/canal-dark/ecossistema/app/

✅ Acessa dessa URL no celular/qualquer lugar!

📌 OPÇÃO 2 — Vercel (AINDA MAIS FÁCIL):

3. Clique "Import"

4. Aguarde o deploy

5. Uma URL pública aparecerá. Acessa: /ecossistema/app/
