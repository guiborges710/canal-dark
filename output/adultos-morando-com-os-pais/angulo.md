# Ângulo: adultos morando com os pais

**Pergunta-gancho:** morar com os pais depois dos 25 é escolha, necessidade ou cultura?

**Tese (lente do canal):** geração é rótulo; contexto é explicação. "Geração canguru" descreve o mesmo comportamento com idades de saída muito diferentes conforme o país. O que muda é o contexto, não a geração.

**Estrutura:** gancho (preguiça?) -> insight (Brasil 2002/2012 com ano dito, e Europa 21,4 x 30,1) -> contraexemplo (EUA: o motor é casamento adiado, não só dinheiro) -> pergunta de volta.
