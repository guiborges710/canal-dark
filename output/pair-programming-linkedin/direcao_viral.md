# Direção — pair-programming-linkedin

## Contexto
Vídeo para LinkedIn, ~15 segundos. Tom direto, dev falando com dev. Sem gancho agressivo, sem pergunta de fechamento forçada. Ângulo: pair programming como knowledge transfer em tempo real.

## Ritmo
Lento e assertivo. Fala pausada, sem pressa. Não é hype — é observação profissional. Cada frase tem peso.

## Clima visual
Folha de caderno, dois bonecos de palito lado a lado na frente de uma tela. Setas bidirecionais entre eles. Simples, limpo, funcional.

## Narração

### Cena 0
Pair programming não é só resolver o problema mais rápido.

### Cena 1
É o momento em que quem ensina organiza o que sabe,
e quem aprende vê o raciocínio acontecendo em tempo real.

### Cena 2
O conhecimento não espera uma reunião ou um documento:
ele se transfere na hora, no código, no erro que aparece.

### Cena 3
É uma das formas mais eficientes de onboarding que existem.

## Picos visuais
- Cena 0: dois bonecos de palito aparecem lado a lado, seta dupla entre eles
- Cena 1: balão de fala saindo de cada boneco simultaneamente
- Cena 2: seta de "conhecimento" fluindo de um para o outro
- Cena 3: check grande, limpo

## Transições
Corte seco entre todas as cenas. Ritmo tranquilo mas sem fusão.
